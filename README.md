# Data Structures & Algorithms with Python

A collection of Python implementations covering fundamental **Data Structures and Algorithms (DSA)**. The repository serves as a storage and reference for implementations, exercises, and problems related to DSA.

## Data Structures

Covers the implementation and usage of:

* Arrays
* Linked Lists
* Stacks
* Queues
* Trees
* Graphs
* Hash Tables

## Algorithms

Includes implementations of common algorithmic techniques and problems:

* Recursion
* Divide and Conquer
* Greedy Algorithms
* Dynamic Programming
* Backtracking
* Sorting Algorithms
* String Matching
* Graph Algorithms and Traversal

The repository may be continuously updated with **new algorithms, data structures, and problem-solving exercises** as more topics are introduced.
