# Algorithmic Strategies

* Greedy: Make the best local choice at each step, hoping to reach a global optimum.
* Divide and Conquer: Split a problem into smaller subproblems, solve them independently, then combine the results.
* Backtracking: Build a solution incrementally and undo choices when they lead to an invalid or unpromising state.
* Dynamic Programming: Solve overlapping subproblems once and reuse their results.
    * Top-Down: Recursion + memoization.
    * Bottom-Up: Iteratively build solutions from smaller cases.
